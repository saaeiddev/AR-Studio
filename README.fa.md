# AR Studio

نسخه اولیه و در حال توسعه ویرایشگر سه‌بعدی تحت وب، ساخته امیر سعید دهقان.

امکان افزودن اشکال اولیه، وارد کردن فایل GLB، انتخاب و تغییر مکان، چرخش و اندازه، ویرایش رنگ، تکثیر و حذف و ذخیره محلی یا خروجی و ورود پروژه JSON فراهم شده است. برای اجرا پوشه را با `python3 -m http.server 8080` اجرا کنید. اتصال اینترنت برای دریافت کتابخانه گرافیکی لازم است.

این نسخه هنوز محصول کامل نیست: واقعیت افزوده، خروجی مستقل وب و خروجی بومی اندروید و iOS، برنامه‌نویسی بصری و انیمیشن پیاده‌سازی نشده‌اند. پیش‌نمایش فعلی فقط سه‌بعدی است. فایل نصب APK یا IPA تولید نمی‌شود. تغییر رنگ GLB پس از بارگذاری مجدد هنوز بازیابی نمی‌شود. پیش از اتکا به پروژه، نسخه پشتیبان JSON تهیه کنید.
