# AR Studio — Create Beyond Reality

نسخه اولیه و در حال توسعه ویرایشگر سه‌بعدی تحت وب، ساخته امیر سعید دهقان. این نسخه هنوز پلتفرم کامل ساخت بازی و اپلیکیشن AR نیست.

امکان افزودن اشکال اولیه، وارد کردن GLB، تغییر موقعیت و رنگ و اندازه، تعریف تعامل ساده چرخش با لمس، پیش‌نمایش سه‌بعدی و ذخیره و بازیابی پروژه JSON پیاده‌سازی شده است. خروجی HTML حاوی داده صحنه و نمایشگر سه‌بعدی است و برای دریافت کتابخانه Three.js به اینترنت نیاز دارد. مسیر آزمایشی WebXR برای قراردادن صحنه روی سطح نیز برای مرورگرها و دستگاه‌های سازگار در خروجی نوشته شده، اما هنوز روی دستگاه واقعی تست نشده است.

برای اجرا از پوشه پروژه دستور `python3 -m http.server 8080` را اجرا کنید. دسترسی دوربین WebXR به HTTPS و مرورگر و دستگاه سازگار نیاز دارد؛ در Safari آیفون نمایش سه‌بعدی جایگزین است. خروجی اندروید و iOS، کدنویسی بصری، قابلیت‌های کامل بازی‌سازی و PWA هنوز آماده نیستند. فایل APK یا IPA تولید نمی‌شود. به علت محدودیت حافظه مرورگر از پروژه نسخه پشتیبان JSON بگیرید.

برای آزمایش‌های فعلی: `node --test tests/*.test.mjs`.

## مدل‌های آماده آزمایشی

از بخش Explore asset library می‌توان مدل مغز، یک مدل ثابت موتور، برد الکترونیکی و مجموعه مدل‌های عمدتاً کم‌جزئیات Kenney را انتخاب کرد. برای مغز نام بخش انتخاب‌شده و در صورت وجود، توضیح انگلیسی نمایش داده می‌شود. توضیح همه بخش‌ها، مدل موتور متحرک و نصب بومی موبایل هنوز آماده نیستند. بارگذاری مدل‌ها به اینترنت وابسته است و عملکرد آن‌ها روی دستگاه واقعی هنوز بررسی نشده است. منبع و مجوز مدل‌ها در ASSET_CREDITS.md آمده است.

## هوش مصنوعی آزمایشی

بخش AI Copilot دارای کادر ورودی نئونی است و با اتصال سرویس هوش مصنوعی، یک صحنه پیشنهادی از مدل‌های موجود تهیه می‌کند. پیش از اعمال، پیشنهاد نمایش داده می‌شود و امکان بازگردانی اشیای افزوده‌شده وجود دارد. این قابلیت هنوز بازی کامل، مدل سه‌بعدی جدید یا خروجی نصب بومی تولید نمی‌کند.

سایت GitHub Pages سمت سرور ندارد و اتصال هوش مصنوعی روی سایت عمومی هنوز فعال نشده است. برای اجرای محلی، روی سرور متغیرهای `OPENAI_API_KEY` و `OPENAI_MODEL` را تنظیم و `node server/ai-server.mjs` را اجرا کنید و آدرس `http://127.0.0.1:8787/` را باز کنید. کلید در مرورگر قرار نمی‌گیرد. اتصال واقعی به ارائه‌دهنده به علت نبود کلید تست نشده است. این سرور فقط برای اجرای محلی است و برای استفاده عمومی به احراز هویت و محدودیت مصرف نیاز دارد.
